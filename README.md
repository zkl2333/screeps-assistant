# Screeps Assistant

**玩家本人的 Screeps AI 助理**

基于 [`screeps-api`](https://github.com/screepers/node-screeps-api) 的外部 API 工具集，帮助你实时监控、分析游戏状态、辅助决策、管理代码部署。

## 快速开始

```bash
npm install
npm run demo:basic
```

详细说明请查看 [AGENTS.md](./AGENTS.md)
